# Grădina Timpului

Static Romanian-language website for Grădina Timpului, a nature retreat in Buzaiel, Vama Buzăului.

The site lives in `src/GardenOfTime.Web/wwwroot` (`index.html`, `styles.css`, `script.js`) and is served by the .NET app; `chat.html` is a standalone chatbot test page. The page is built with plain HTML, CSS, and JavaScript; its editorial photographs and typefaces load from external services.
